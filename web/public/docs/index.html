LPS API 接口文档

统一的 OpenAI 兼容模型接口，支持普通响应、流式响应和 Anthropic Messages。

API 地址：https://lpss.online/v1　官方链接：https://lpss.online

鉴权

在请求头中携带站内 API Key。请勿把 Key 写入公开代码、前端脚本或日志。

Authorization: Bearer sk-你的站内Key

OpenAI Chat Completions

curl https://lpss.online/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的站内Key" \
  -d '{
    "model": "gpt-5.5",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": false
  }'

也可将 Base URL 配置为 https://lpss.online/v1，直接使用 OpenAI SDK。

from openai import OpenAI

client = OpenAI(
    api_key="sk-你的站内Key",
    base_url="https://lpss.online/v1",
)
result = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "你好"}],
)
print(result.choices[0].message.content)

图片生成

curl https://lpss.online/v1/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的站内Key" \
  -d '{"model":"gpt-image-2","prompt":"一只坐在窗边的猫","size":"1024x1024"}'

图片请求按次计费，返回格式遵循 OpenAI Images API。

流式响应

在请求中设置 stream: true，服务通过 SSE 返回增量内容。

curl -N https://lpss.online/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的站内Key" \
  -d '{"model":"gpt-5.5","messages":[{"role":"user","content":"你好"}],"stream":true}'

Anthropic Messages

curl https://lpss.online/v1/messages \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的站内Key" \
  -H "anthropic-version: 2023-06-01" \
  -d '{
    "model": "gpt-5.5",
    "max_tokens": 512,
    "messages": [{"role": "user", "content": "你好"}]
  }'

工具调用

支持 OpenAI 的 tools、tool_choice 和 tool_calls。tool_choice 使用 none、auto 或 required。

常见错误

状态含义处理建议
401Key 无效或已停用检查 Authorization 头和站内 Key 状态
402额度不足检查余额或联系管理员
400请求参数或模型能力不匹配检查 model、messages、max_tokens 和工具参数
429请求过于频繁降低并发并按退避策略重试
5xx服务或上游暂时异常稍后重试，并记录 response id；上游余额或日限额耗尽时请等待恢复
